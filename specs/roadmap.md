# Roadmap

High-level implementation order. Each phase should be fully working before the next begins.

1. **Project scaffolding** — repo, tooling, CI, environment config
2. **Walking skeleton** — end-to-end hello-world across every layer (UI → API → DB)
3. **Data model** — schema design and migrations for users, imports, and sync records
4. **CSV import** — file upload, parsing, validation, and bulk insert
5. **CRM sync** — API client, field mapping, and sync job queue
6. **Progress status page** — live import and sync status with real-time updates
7. **In-app notifications** — notify users on import completion or failure
8. **Polish pass** — UI refinement, error states, performance, and cross-browser QA
