# Tech Stack

| Layer | Technology |
|---|---|
| Language | TypeScript |
| Framework | Next.js |
| Styling | Tailwind CSS |
| Database | PostgreSQL |
| ORM | Prisma |
| Queue | BullMQ (Redis-backed) |
| Real-time | Server-Sent Events or WebSockets via Socket.io |

**Rationale:** All choices are typed, actively maintained, and widely adopted — satisfying engineering's requirement for a reliable, popular TypeScript-based stack. Next.js provides full-stack routing, API routes, and SSR in a single project. Tailwind ensures a polished, consistent UI that works well in modern browsers.
